HOW IT CHANGES

サロン経営に必要な数字を、ひとつに。

売上だけではなく、 人件費・材料費・固定費・目標までまとめて管理。 目標に対する現在の達成率や、 月末の着地予想、 残り営業日に必要な売上まで確認できます。

オーナーだけでなく、権限に応じてスタッフにも必要な数字だけを共有できます。

FEATURES

主要機能

サロン経営に必要な数字を、ひとつの画面で。

📈

売上・営業進捗

今のペースで目標に届くのかを、毎日すぐ確認。

  • 月累計売上
  • 営業日数 / 残り営業日
  • 1日平均必要売上
  • 月末着地予想
🎯

目標と現在の達成率

目標を設定して終わりではなく、現在どこまで達成しているのかをリアルタイムで確認。残りいくら必要なのかまで分かるため、月末から逆算して行動できます。

  • 目標売上 / 現在の売上
  • 現時点の達成率
  • 残り必要売上 / 残り営業日
  • 1日あたり必要売上
💰

損益管理

売上だけではなく、実際にいくら利益が残るのかまで確認。

  • 人件費
  • 材料費 / 発注費
  • 固定費 / その他費用
  • 利益
🧮

利益から逆算

人件費率や仕入れ率などを設定し、売上に応じた想定費用を自動計算。今月あといくら売れば利益が残るのかを、経営判断の途中指標として確認できます。金額は必要に応じていつでも編集できます。

🗓️

月間目標管理

売上だけでなく、サロン運営に必要な目標をまとめて設定。実績と目標を同じ画面で確認できます。

  • 目標売上 / 技術売上 / 店販売上
  • 客数 / 客単価
  • 新規 / 再来
🔐

必要な数字だけ、必要な人に。

オーナーだけでなく、スタッフごとに閲覧できる範囲を分けて管理。経営に関わる数字をすべて公開するのではなく、役割に応じて必要な情報だけを共有できます。

  • 会社全体を確認する管理者
  • 複数店舗を確認する管理者
  • 自店舗を管理する店長
  • 日々の数字を確認するスタッフ
🤝

チームで目標を追える

店舗の目標や進捗を、オーナーだけでなく現場でも共有。今どこまで達成しているのかを確認しながら、チームで同じ数字を追える環境をつくります。

🏬

複数店舗管理

複数店舗の数字をまとめて確認。店舗ごとの進捗や売上を比較し、全店舗の状況を1つの画面から把握できます。

1店舗から利用できます
✍️

GOAL MANAGEMENT

目標を立てて終わりにしない。

今日の時点で、目標の何％まで来ているか。

月間目標を設定すると、現在の売上から達成率を自動で確認できます。さらに、残り必要売上・残り営業日・1日あたり必要な売上・月末着地予想まで確認できるため、「月末になってから未達に気づく」状態を減らします。

目標達成率 残り必要売上 残り営業日 1日あたり必要売上 月末着地予想

ROLE-BASED ACCESS

オーナーだけの数字管理で終わらせない。

経営数字は重要ですが、全スタッフにすべてを見せる必要はありません。サロンマネージャーでは、役割に応じて閲覧できる範囲を管理。オーナー・管理者・店長・スタッフなど、必要な人に必要な数字だけを共有できます。

会社管理者自社の全店舗の数字を横断して確認できます
店舗管理者(店長)担当する自店舗の数字を確認・管理できます
一般スタッフ許可された範囲の日々の数字を確認・入力できます

HOW IT WORKS

毎日の経営確認を、もっとシンプルに。

1

目標を設定

月間の目標売上・客数などを設定します。

2

売上・客数などを入力

毎日、またはまとめて数字を入力します。

3

達成率・着地予想・利益を確認

今の状況が自動で見える化されます。

4

必要な数字をスタッフと共有

権限に応じて、見せたい数字だけを共有します。

5

数字を見ながら次の行動を決める

感覚ではなく、数字を根拠に経営判断できます。
